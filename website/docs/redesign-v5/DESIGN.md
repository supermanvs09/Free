# Redesign v5: "Indigo night"

Replaces the rejected v3 (dark graphite) and v4 (light sky) passes.

- **Look:** one dark indigo theme for every page (#070818), violet-blue light behind heroes, rounded glass cards, pill buttons. Taken from the dark SaaS shots: Zifon 17, Volectra 28, Outnex 54/68, Markiq 70, Dope.ai 80, Flock 92.
- **No grid backdrops** anywhere.
- **Voice:** short, strong framing sentences in the Quantra manner (shot 26): "Stop the attack that logs in.", "Why us? Because a valid login isn’t a safe one.", "Just connect. Nothing to rip out.", "Watch it decide. Live." The look is not copied from Quantra.
- **Type:** Funnel Display headings, Geist body, Geist Mono labels.
- **Motion:** word-by-word headline rise, live particle wave behind the hero, floating glass cards, scroll-lit statement, masked photo reveals with parallax, logo marquee, integrations orbit, sticky how-it-works, count-up figures. Every effect has a reduced-motion final state.
- **Removed:** the product tour page (`/product-tour` redirects to `/products` with a 301).
- **Contrast:** body text 11.9:1, secondary 7.2:1, captions 6.3:1 on the page; white on the button violet 6.3:1.

Every reference shot is mapped to where it is used in `SHOT_MAP.md`.
