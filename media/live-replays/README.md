# Live replay recordings

Screen recordings (no audio, 1920×1080 at 30 fps, H.264) of the six live scenarios, for sharing
outside the console. The app does not load these files: inside the console,
Ctrl+Shift+L plays the scenarios live.

| File | Scenario |
|---|---|
| `1-leaked-iam-key.mp4` | Leaked IAM access key |
| `2-ec2-role-stolen-via-imds.mp4` | EC2 role credentials stolen via IMDS |
| `3-privilege-escalation-assumerole-chain.mp4` | Privilege escalation through an AssumeRole chain |
| `4-orphaned-role-after-lambda-deleted.mp4` | Orphaned role after its Lambda was deleted |
| `5-runaway-bedrock-ai-agent.mp4` | Runaway Bedrock AI agent |
| `6-known-credential-unknown-consumer.mp4` | Known credential, unknown consumer (Vault-stored key used from a third source, rotated in Vault) |
| `nhi-live-replays-all-six.mp4` | All six, one after another |
